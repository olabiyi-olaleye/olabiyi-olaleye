### Hi, I'm Olabiyi

I'm a software engineer in Lagos. Most of what I build is React, Next.js and React Native, usually for products that take payments, manage bookings or run events in Nigeria. I write TypeScript on the front end, Node behind it, and I use a lot of SQL when the numbers in production stop adding up.

I studied Economics before I moved into software, so data work comes naturally to me too. I build dashboards in Power BI and Excel and like knowing what the data says before I change any code.

More about me and my work at [olabiyi-portfolio.vercel.app](https://olabiyi-portfolio.vercel.app).
